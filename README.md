# LOGAX Hub

The LOGAX Hub page. The desktop launcher on the shop PC downloads `index.html` from this repo each time it opens, so anything pushed to `main` reaches the shop automatically.

- The launcher downloads `index.html`, `scripts/server.ps1` and `scripts/start.ps1`. Keep the page one self-contained file.
- No passwords, keys or private info in this repo. It is public.
